# 制作与验收

按本次交付类型读取对应分支。所有分支共用文末的内容和视觉检查，不把图片、矢量文件、可编辑对象混称为同一交付物。

## 1. 整页图片与独立配图

1. 核对参考页及文案，明确画布比例、版心、主体布局、文字和保留内容；填写 [提示词模板](prompt-templates.md) 的对应分支。整页图片包含用户要求的全部页面元素；独立配图不自行加入整页标题或正文。
2. 图像生成时区分风格参考、编辑目标、证据素材。提示词写明图形要解释的关系、准确文字和保护项。用户要求保持原样的区域，不作为可自由重绘的内容。
3. 概念场景、机制插画可用当前可用的图像生成工具；精确结构可采用适合的确定性绘图。工具选择服从当前要求和实际能力，没有所需工具时说明缺项，完成不依赖该工具的文案或版式准备。
4. 论文原图、真实截图、数据曲线、精确公式、文献条目与大段正文，使用原素材或受控排版。即使最终交付为 PNG，也可先做可控文字层、矢量图层与证据图层，再统一导出。不能通过生成模型描摹来保证数值保真。
5. 保持比例和清晰度。清晰度按最终展示尺寸判断，不能仅因文件像素大就宣称清晰。文字较小时先删减重复内容或调整结构，再考虑缩字。
6. 本次要求透明时实际检查alpha：透明区域不能只是白色或棋盘格图案；其他任务的背景按当前要求和页面样式确定。
7. 逐张打开最终文件，核对当前语言的文字、符号、上下标、公式关系、图例和箭头。生成模型对字体、文字或布局的承诺不能替代最终检查。交付清晰图片，按任务及实际工具要求保存最终提示词；不擅自改变用户指定的文件形式。

## 2. 可编辑复刻与 PPTX

执行者尚未明确时，按 `SKILL.md` 的“可编辑制作与复刻的执行者”询问并等待。用户已选择自己完成时，只交付本次需要的参考图、素材或简短说明；已明确交给 agent 时直接执行下列步骤，不重复询问。

1. 读取当前环境可用的演示文稿工具说明及相关技能，选择能满足本次输出与编辑要求的后端。
2. 复刻前列出元素与关系：文字、公式、图形、连接线、表格、数据图、照片及证据截图。为用户要求可编辑的元素确定原生对象；证据图片按内容性质保留，不凭空重画为虚假数据。
3. 重建位置、大小、层次、颜色、线型、箭头方向、上下标和字距。参考图可作私有定位底稿；最终不能用它覆盖新对象来制造视觉一致，也不能保留整页底图而宣称已完成原生复刻。
4. 普通文字、图例和图形可单独修改；公式采用当前后端实际支持的可编辑表示。若某公式或图表只能以局部图片保留，说明该项，不宣称全部可编辑。矢量 SVG 作为单个图片插入，不自动等于其文字、曲线和节点可在 PPT 中分别编辑。
5. 按参考图尺寸渲染，对比文字换行、对齐、配色、曲线、图例及连接拓扑；使用并排、叠加或差异图辅助检查。抗锯齿会影响像素差，但不能用它掩盖错字、错位和缺失。无法达到用户要求的一致程度时明确剩余差异。
6. 检查相关对象的真实类型和内容；能使用目标编辑器时，实际选取并修改代表性文字、图形或图表后验证保存。不能实际编辑验证时，说明只检查了结构与渲染，不声称已在 PowerPoint 中验收。

## 3. 科学证据图

记录当前证据类型及可追溯来源，如文献位置、原始图像或数据文件；时间、版本与研究条件在影响解释时注明。涉及定量展示时核对变量、指标定义与单位。重绘时保留数据与变换说明；归一化、筛选、平滑、分箱或聚合须有依据并可复查，不为美观改变结果。

检查顺序：

1. 所有证据先核对来源、原内容、图注或摘录与解释是否一致，处理是否保留必要上下文。
2. 展示数据系列时，核对系列、图例、线型或标记的一一对应；展示定量坐标时再核对轴、单位、尺度与基准。
3. 涉及跨材料或方案比较时，核对取得条件、定义及可比范围；条件不同不能直接归因或计算改善。
4. 结论必须由实际材料支持；区分观察、解释、推导、近似和概念示意，不把某一类证据要求套到所有研究。
5. 采用统计分析时，核查样本、统计范围与不确定性定义；误差条或区间按其实际定义核对，不预设为统计结果。非统计研究不强加样本字段，所缺数值也不被补造。
6. 图形编码在实际展示条件下可辨，必要时结合标记、线型或直接标签；遵守本次风格要求，不单凭颜色暗示证据强弱。

图形简化可以减少无关装饰和说明，但不能删除改变结论的条件、点或曲线。没有数据的示意图可以夸大概念差异以便理解，必须标明示意且满足模型关系，不能加上伪造精确数值。

## 4. 截图与局部修改

使用截图或图像记录时保留原件，标注版与原件分别保存；更新素材时保留版本对应。标注的颜色和图形语言服从当前要求；图中内容、数值和原有解释保持一致，不能以标注或修饰改变证据。

在授权区域或对象内编辑；不要顺便重画整张图。可用受控蒙版或原生对象完成时，优先采用确定性编辑。按约定保护区及保留精度核对差异；要求像素不变时，蒙版外像素差应为零。增加边距或改变位置时记录映射后再比对。原件本身不被修改。

PPT 原生对象局部修改时，检查未授权对象的文字、位置、大小、顺序和样式，并结合相同设置的渲染差异核对。不同渲染器带来的像素差不直接等于内容被改动。

已有记录仅支持其对应时间与条件下的陈述，不冒充新取得的证据。演示稿制作不自动扩大为新实验、调查、数据采集或外部资源操作；需要新增研究材料时先明确所需范围与现有授权。

## 5. 双重验收与交付条件

按 [checklist](checklist.md) 复制任务记录、共用项及本次触发的分支，逐项记录真实证据。该文件提供可勾选的准备、整页、素材透明、科学证据、局部保留、复刻执行者与批量检查；不是仅凭印象打分的总表。

只有已检查并满足条件的项勾选；失败、未检查和不适用分别注明理由。纯讨论不强行生成图片，可编辑复刻未选择执行者时继续等待；不以填写清单扩大制作权限。

复杂批量任务可让独立子 agent 检查最终文件与任务要求，再核实其发现。自动验证器、OCR 和子 agent 只能覆盖各自检查项；没有证据时不能宣称全部通过。修复后检查新的最终文件，交付时简洁说明影响使用的局限。
