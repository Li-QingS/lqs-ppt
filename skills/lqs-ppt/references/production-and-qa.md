# 制作与验收

按本次交付类型读取对应分支。所有分支共用文末的内容和视觉检查，不把图片、矢量文件、可编辑对象混称为同一交付物。

## 1. 整页图片与独立配图

1. 核对参考页及文案，明确画布比例、版心、主体布局、文字和保留内容。整页图片包含用户要求的全部页面元素；独立配图不自行加入整页标题或正文。
2. 图像生成时区分风格参考、编辑目标、证据素材。提示词写明图形要解释的关系、准确文字和保护项。用户要求保持原样的区域，不作为可自由重绘的内容。
3. 概念场景、机制插画可用当前可用的图像生成工具。历史中的 `image2.5` 是当时的工具称呼，不据此指定当前不存在的接口；没有可用工具时，说明能力缺口，完成不依赖该工具的文案和版式工作。
4. 论文原图、真实截图、数据曲线、精确公式、文献条目与大段正文，使用原素材或受控排版。即使最终交付为 PNG，也可先做可控文字层、矢量图层与证据图层，再统一导出。不能通过生成模型描摹来保证数值保真。
5. 保持比例和清晰度。清晰度按最终展示尺寸判断，不能仅因文件像素大就宣称清晰。文字较小时先删减重复内容或调整结构，再考虑缩字。
6. 透明背景实际检查 RGBA/alpha：透明区域不能只是白色或棋盘格图案。没有透明要求时沿用所在页面背景，不把某次“白底”或“透明”偏好扩展到所有配图。
7. 逐张打开最终文件，核对中文、上下标、公式关系、图例和箭头。生成模型对字体、文字或布局的承诺不能替代最终检查。交付清晰图片，按当前技能要求附保存的最终提示词；不擅自把 SVG 或 PPTX 当作用户要求的 PNG 替代品。

## 2. 可编辑复刻与 PPTX

先按 `SKILL.md` 的“可编辑复刻前先选择执行者”询问并等待用户选择。用户自己复刻时，只交付本次需要的参考图、素材或简短说明，不创建或修改 PPTX；用户明确交给 agent 后，才执行下列制作和验收步骤。已经明确的执行者选择不重复询问。

1. 读取当前环境的演示文稿技能及其实现文档；按当前可用后端执行。不把历史会话中的工具链固定为所有环境的唯一选择。
2. 复刻前列出元素与关系：文字、公式、图形、连接线、表格、数据图、照片及证据截图。为用户要求可编辑的元素确定原生对象；证据图片按内容性质保留，不凭空重画为虚假数据。
3. 重建位置、大小、层次、颜色、线型、箭头方向、上下标和字距。参考图可作私有定位底稿；最终不能用它覆盖新对象来制造视觉一致，也不能保留整页底图而宣称已完成原生复刻。
4. 普通文字、图例和图形可单独修改；公式采用当前后端实际支持的可编辑表示。若某公式或图表只能以局部图片保留，说明该项，不宣称全部可编辑。矢量 SVG 作为单个图片插入，不自动等于其文字、曲线和节点可在 PPT 中分别编辑。
5. 按参考图尺寸渲染，对比文字换行、对齐、配色、曲线、图例及连接拓扑；使用并排、叠加或差异图辅助检查。抗锯齿会影响像素差，但不能用它掩盖错字、错位和缺失。无法达到用户要求的一致程度时明确剩余差异。
6. 检查相关对象的真实类型和内容；能使用目标编辑器时，实际选取并修改代表性文字、图形或图表后验证保存。不能实际编辑验证时，说明只检查了结构与渲染，不声称已在 PowerPoint 中验收。

## 3. 科学证据图

先记录来源：论文位置或原始数据文件、采集日期、仿真/硬件、运行条件、指标定义和单位。重绘时保留数据与变换说明；有归一化、筛选、平滑、分箱或聚合时，须有依据并可复查，不为美观改变结果。

检查顺序：

1. 每条线和每组点对应什么；图例颜色、线型、标记是否一一对应。
2. 横纵轴、单位、对数尺度、比较方向、基准与统计窗口是否准确。
3. 不同图或不同方案是否具有可比条件；不同比较口径不能直接计算“提升”。
4. 结论是否由实际图和数据支持；数值结果、理论界、近似和概念示意分别标清。
5. 如展示误差条或区间，注明统计含义与样本单位；原材料没有不确定性时不虚构误差范围。
6. 颜色之外必要时增加线型、标记或直接标签，确保投影时可辨；服从用户要求保留的具体风格与图例。

图形简化可以减少无关装饰和说明，但不能删除改变结论的条件、点或曲线。没有数据的示意图可以夸大概念差异以便理解，必须标明示意且满足模型关系，不能加上伪造精确数值。

## 4. 截图与局部修改

真实软件页面使用实际运行截图。分别保存原始截图和功能标注，保持原图完整；新采集新建带日期或版本的目录。通过红字、红框和箭头说明功能时，原有坐标轴、曲线、界面值及其含义保持一致。

在已授权的图例或标注区域内编辑；不要顺便重画整张图。可用受控蒙版或原生对象完成时，优先采用确定性编辑。位图编辑后检查蒙版外像素差为零；加外边距的标注图，先按记录的偏移和比例映射原截图区域，再检查该区域内未覆盖像素。原始截图本身不被修改。

PPT 原生对象局部修改时，检查未授权对象的文字、位置、大小、顺序和样式，并结合相同设置的渲染差异核对。不同渲染器带来的像素差不直接等于内容被改动。

历史硬件截图仅证明其对应日期与条件下的状态。没有新测量时，不冒充当前硬件结果；缺少设备时不自动启动射频或把新硬件采集扩大为 PPT 制作的必做事项。需要新增采集时，另按当前用户授权、设备状态和项目规定执行。

## 5. 双重验收与交付条件

| 检查 | 合格条件 |
|---|---|
| 覆盖与阶段 | 页数、页序、范围和交付类型符合本次请求；涉及可编辑复刻时，执行者已明确；遵守用户选择与“先讨论”等限制 |
| 逻辑与科学内容 | 术语已解释、公式与符号有依据、关系明确、图文相符、结论有证据 |
| 视觉 | 实际最终文件已打开检查，文字可读、比例协调、对齐清楚、无遮挡裁切 |
| 局部保留 | 指定保留内容经对象比较或像素检查未改变 |
| 文件与编辑性 | 输出格式正确；PPTX结构与要求的对象编辑层级分别验证 |
| 来源与引用 | 真实数据、概念示意、日期和引用可区分并追溯 |

复杂批量任务可让独立子 agent 检查最终文件与任务要求，再核实其发现。自动验证器、OCR 和子 agent 只能覆盖各自检查项；没有证据时不能宣称全部通过。修复后检查新的最终文件，交付时简洁说明影响使用的局限。
