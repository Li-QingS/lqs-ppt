# 制作与交付 Checklist

每次按本次任务复制“任务记录”“共用项”及实际触发的分支到私有工作记录。先做准备项，制作后检查最终产物；每张页面或独立素材分别记录，批量任务最后再做批量项。纯讨论只做范围、内容与文本交付项，图像、透明或PPTX项标不适用，不为走清单扩大任务。

## 记录规则

- `- [x]` 仅表示**已验证通过（PASS）**，后面附简短证据，如文件名、源图位置或实际检查结果。
- `- [ ] FAIL：原因` 表示实际检查发现不符合；`- [ ] 未检查：原因` 表示尚未执行或缺少所需材料/工具。二者不能改写成通过。
- `- [ ] N/A：理由` 仅用于本任务不适用的检查，例如不含透明要求的整页图。没有数据、未打开图片或没有工具，不是N/A的理由。
- 状态按记录对象填写：本次只要求讨论或提示词文本时，图像分支可记N/A；本次要求图片/PPTX但文件尚未生成时，对应产物项记“未检查”。同时记录文本准备与目标产物时分开标明对象，文本准备通过不能代替图片/PPTX验收通过。
- 提示词写了要求、工具返回了文件、文件名包含“最终”或子agent说“通过”，都不单独证明产物合格。检查后修复的项目，要对新版本重新检查。
- 范围、科学证据、准确文字、保护区域及要求的文件/编辑属性有FAIL或未检查时，继续补证或修复；确实无法完成则说明缺项，不宣称完整验收。此表不新增用户审批，也不替用户选择复刻执行者。

## 任务记录

```text
任务/页面或素材标识：
阶段：讨论 / 制作 / 验收
交付：文本 / 整页PNG / 独立配图 / 局部修改 / 可编辑PPTX
当前已确认要求及保留区域：
复刻执行者：用户 / agent / 不涉及；选择依据：
内容与样式参考：
采用模板：A / B / C / D / E / 不涉及
最终提示词或制作任务书文件：
实际最终产物及版本：
本次适用分支：
```

## 1. 共用：制作前

- [ ] 阶段与交付已明确：遵守“先讨论/不生图/不操作原PPT”等限制，页数与页段来自本次请求。
- [ ] 若涉及可编辑重建，执行者已由用户明确选择；无回答时等待，当前已选过时不重复询问。不涉及时注明N/A。
- [ ] 已读实际内容与风格参考，标清“内容来源/风格参考/编辑目标/证据图”；未取得的参考不假装已查看。
- [ ] 本页主旨、必要文字与图形关系明确；相邻页分工不同，箭头起终点与含义具体。
- [ ] 科学术语、符号、数字与结论可追溯；待核实项已列出，未补造事实、条件或文献。
- [ ] 涉及制作时，已选并填好实际使用的提示词/任务书：无遗留`{{…}}`字段，准确文字、版式、素材角色、允许变化与保留项齐全；未擅自套用示例色值或比例。
- [ ] 工具与所需能力实际可用；提示词意图和接口参数已分开，没有把未支持字段当作工具保证。纯讨论注明N/A。

## 2. 共用：内容、视觉与交付

- [ ] 图文相互解释：看图能概括主旨，文字能说明图形关系；没有用单一icon代替困难、机制或结论。
- [ ] 最终文字已逐字核对，包括标题、标签、下标、单位、图注与引文；没有漏字、乱码、生成出的伪文字或多余句子。
- [ ] 对实际最终文件已做相应检查：文本读其最终内容；图片打开；PPTX渲染后查看。检查对象就是将交付的版本。
- [ ] 图像/页面按最终显示尺寸可读：文字与线条清晰，未靠像素数或提示词字号断言合格；无裁切、遮挡、比例失调或区域混淆。纯文本注明N/A。
- [ ] 样式与有效参考一致：字体、主辅色、版心、标题位置和强调语义协调；中文/字母数字字体与字号偏好在其适用范围内使用。
- [ ] 结论只覆盖已验证证据及对应日期、条件；无数据的概念图有清楚的示意语境，未冒充实验结果。
- [ ] 所需最终文件真实存在、可读且格式正确；名称/顺序与交付范围一致，源文件及受保护区域未被擅自覆盖。
- [ ] 已保存实际使用的最终提示词或制作任务书；交付内容按用户及所用技能要求组织，没有把检查过程、私有路径或中间失败版本塞进页面。

## 3. 整页图片分支

- [ ] 交付为完整页面：包含本次要求的标题、图文与标注，不是只给配图，也没有屏幕/相框等展示外壳。
- [ ] 画布比例、版心、背景与布局来自当前参考或已声明的本次设置；没有把特定项目的2/3布局或固定页数硬套过来。
- [ ] 内容丰满来自解释性视觉与必要信息；无无用大空白、重复图形、拥挤小字或卡片墙。
- [ ] 需要受控文字或原始证据时，已与概念视觉正确合成；用户要求完整页图时未只交未排字的背景。

## 4. 独立素材与透明分支

- [ ] 只有指定配图及必要标签，没有擅加整页标题、正文、页码或文献栏；比例适配实际占位，主体未裁切。
- [ ] 同一对象与各场景/状态的对应清楚，固定/变化部分可见；未用夸张示意暗示未经测量的性能收益。
- [ ] 若要求透明，已查实际alpha：背景存在透明区域，不是白色矩形或棋盘格；边缘无错误抠除。非透明任务注明N/A。
- [ ] 透明素材已叠在目标背景和明暗测试底上查看，文字、细线和轮廓无明显白边或残留底板。非透明任务注明N/A。
- [ ] 最终交付仍是用户要求的图片格式；没有用SVG/PPTX文件替代PNG，也没有只交提示词冒充已完成图片。

## 5. 科学证据与成果合成分支

- [ ] 每张图有来源、仿真/硬件或论文图分类、采集/运行日期及影响结论的条件，文件整理日期没有冒充采集日期。
- [ ] 原图/真实数据保真：未让生图模型描摹曲线、坐标、截图、数值或精确公式；重绘时有源数据与变换记录。
- [ ] 图例与曲线/点对应，横纵轴、单位、尺度、比较方向及基准正确；与原材料逐项核对。
- [ ] 比较条件和指标口径一致；不一致处分别说明，没有把SER、EVM、CRC等未经核实字段直接写成改善或通过结论。
- [ ] 涉及统计结论时，样本量/统计窗口与不确定性定义可核实；材料没有提供时未虚构误差条或改善比例。
- [ ] 图外标注、裁切与等比例缩放保留必要上下文；页底结论和本页出处由证据支持且可读。

## 6. 局部修改与截图标注分支

- [ ] 已定位允许修改的对象或蒙版范围，列出保留项，使用原生编辑或受控合成满足实际精度要求。
- [ ] 新文字、颜色或对象符合本次指定，原曲线、坐标、数据与其他图例未被顺便改写。
- [ ] 位图在同尺寸/对应坐标下核对保护区：要求不变的蒙版外像素差为零。外加边距时按原图偏移映射后比较；非位图说明N/A。
- [ ] 原生PPT局部编辑已比较未授权对象的内容、几何、层次与样式，并以相同设置渲染复核；非原生编辑说明N/A。
- [ ] 原始截图与标注图分别保存；当前/历史硬件与仿真来源准确，原图本身未被修改。非截图任务说明N/A。

## 7. 复刻执行者分支

用户自己复刻时：

- [ ] 只交付本次所需参考图、配图或简短复刻说明；没有创建/修改可编辑PPTX，也未把用户的未完成工作宣称为agent成果。
- [ ] 素材、准确文字和必要样式说明与用户计划匹配；只需素材时不附加多余整页或教程。无要求的项目说明N/A。

agent复刻时：

- [ ] 已记录用户明确选择，按实际可用演示工具制作，普通文字、图形与连接线等要求可编辑的元素具有对应原生对象。
- [ ] 真实证据图片保留原件；只能作局部图片的项已说明；未用整页底图、单个SVG或图片拼图冒充原生可编辑。
- [ ] 包结构检查与实际对象类型/内容检查分别通过；能打开文件本身不作为编辑性证明。
- [ ] 已按参考图同尺寸渲染，核对文字换行、对齐、颜色、图例、连接拓扑与可见差异。
- [ ] 有目标编辑器时已对代表对象修改、保存、重开并渲染验证；无该能力时记录“未检查”及实际结构/渲染范围，不宣称目标编辑器已验收。

## 8. 批量任务分支

- [ ] 请求页段/素材与最终文件一一对应，数量、顺序及关联标签一致，没有漏页或混入中间稿。
- [ ] 每张产物分别通过适用检查，同类配色、字体、图例语义与清晰度一致，不能只抽一张代替整批。
- [ ] 独立子agent如参与，只记录其实际覆盖范围；已核实其发现，对修复后的最终版本复查，不把整体“通过”替代逐项证据。

## 完成记录的写法

```text
- [x] 已明确只交独立透明PNG；输入为本次用户要求。
- [x] 提示词B已填写；准确标签将由受控文字层加入，未留下模板字段。
- [ ] 未检查：尚未生成文件，未验证alpha、最终尺寸可读性或图中文字。
- [ ] N/A：本任务只解释概念机制，不包含或声称真实曲线、实验结果，真实曲线的数据一致性分支不适用。
```

这个例子只证明已确定任务与提示词，不代表图片已完成。清单保存为工作记录；只有用户要求时再交付完整清单，平时简洁说明影响使用的实际缺项。
