# 生图提示词与制作任务模板

## 用法与模板选择

先从本次用户要求、已确认文案与有效参考页填充模板。`{{…}}` 是需要 agent 填写的字段，不是发给用户的问卷；无需逐项向用户询问。发送给工具前替换所有字段，删除不适用行，只对影响科学含义或交付的缺失信息澄清。不要把此文件整份塞进生图请求。

| 类型 | 采用模板 | 执行方式 |
|---|---|---|
| 纯概念示意的整页，不含需要保真的证据或精准排版 | A | 生图；最终页逐字与视觉复核 |
| 独立机制图、场景插画、透明配图 | B | 生图或适合该素材的确定性绘图；不添加整页元素 |
| 已有概念插画只换局部 | C | 编辑目标；有精确保留要求时用受控合成与差异核对 |
| 含原始图像、文献/观察记录、原文摘录、数据图或精准排版内容的整页 | D | 发给排版/合成工具的制作任务书；证据本身不交给生图重画 |
| 已选择由 agent 制作可编辑 PPTX | E | 发给演示文稿制作工具的任务书；不是生图提示词 |

不确定材料是否作为研究证据时，先核查来源与用途；不能自行标成“示意”后允许重画。最终交图片不改变证据保真要求。背景图片可独立生成，再与原始证据和受控文字合成完整页面。

### 每次实例化必须确定的内容

说明交付物与本页主旨；为实际提供的每张图标出“风格参考/编辑目标/必须保留的证据/待插入素材”；写清视觉关系、准确文字、版式、保留项与可改变项。原生对象或像素零差异属于验收要求，不是生图模型能保证的属性。

模板中的“画幅、字体、透明、输出格式”是制作意图；工具参数仅使用实际接口支持的字段。提示词不能证明最终文件已达到要求。语言、字体、字号、颜色和布局取自本次参考或明确的设计选择；没有参考时按当前书写系统、符号和显示条件确定，不预设主题。所有文字按最终插入尺寸检查。

## A. 科研整页图片：可直接填充后发送的生图提示词

```text
请制作一张可直接整页插入科研PPT的完整页面图片，不是局部插画，也不是放在电脑或屏幕中的展示模型。
页面用途：{{背景/问题/研究思路/架构等本次页型}}；听众：{{本次听众}}。
本页唯一主旨：{{一句话说明听众应理解什么}}。
输入图片：{{实际提供的图像编号与角色；没有输入图则写无}}。
参考继承：{{画幅比例、标题位置、版心、背景、主辅色、强调色、线条及图形风格}}；只继承参考的样式，不照抄其中与本页无关的内容。
画面组织：{{主图位置与面积、辅助说明区域、阅读顺序、区域间对齐与留白；比例按本页确定}}。
主图必须画出的关系：{{有哪些对象、各对象作用、箭头起终点及含义、前提与结果、对比中哪些相同哪些不同}}。
必须出现的文字（逐字使用，不增删）：
标题：“{{准确标题}}”
图内标签：“{{标签1}}”“{{标签2}}”{{按需继续列出}}
必要短正文：“{{已核实的简短正文；无则删此行}}”
结论：“{{本页需要且有依据的结论及呈现位置；无则删此行}}”
文字要求：{{当前语言与书写系统、字体、符号排版、字重、强调方式与位置}}，文字在最终PPT显示尺寸清楚，不压到图形和箭头。
图文对应：通过{{具体视觉差异或联系}}说明主旨；文字与图表达同一关系，不用无含义的icon代替机制。
内容边界：{{哪些是概念示意、哪些事实已核实}}。本页不绘制虚构测量值、实验曲线、公式或参考文献。
必须保留：{{本次已确认的布局、内容或形象；没有则删此行}}。
避免：无助于解释的装饰、重复内容、无用大空白、拥挤小字、未定义符号、裁切文字、额外文案或水印。
输出意图：{{沿用参考页比例的完整画面及背景}}，只包含这张科研页面，不带相框、屏幕和额外页面。
```

若文案不能由模型可靠逐字呈现，转为只生成所需概念视觉，再用受控文字层组成完整页。保留标题、正文、公式和引文的准确文本，不把乱码或近似文字当作成品交付。

## B. 独立科研配图：含透明背景选项

```text
请生成一张用于科研PPT中{{占位用途}}的独立配图，不是整页PPT。
这张图只解释：{{一个机制、对比或关系}}。
输入图片及角色：{{实际图像编号；风格参考与编辑目标分开写}}。
对象：{{对象清单、每个对象的语义、相同对象是否只出现一次}}。
关系与图形动作：{{连接含义与方向、步骤顺序、分组对照或变化前后怎样对应}}。
布局：{{目标占位比例、各部分相对位置、对齐方式、留出放大后可读文字的空间}}。
视觉风格：{{参考页的具体学术绘图特征、色彩及线宽；不要擅自套用其他项目色值}}。
文字模式：{{按本次要求选择：最终素材无文字；生图无文字且后续受控添加指定标签；或直接保留准确短标签}}。
准确标签：“{{逐项列出的文字；无文字时删除本行}}”。不自行增加标题、解释句、页码或文献栏。
科学约束：{{本图必须成立的关系、示意与实测的界限；哪些内容不能暗示}}。
背景：{{透明/与目标页面一致的背景，按本次请求只保留一种}}。
若要求透明：生成真实透明背景，轮廓与文字边缘清楚，没有白色矩形、棋盘格图案或不必要的投影底板。
输出意图：{{所需画幅和素材格式}}，主体完整，不裁切；仅交该素材，不拼成整页。
```

无文字模式时，先删除准确标签行；需要准确标签时，逐字核对并可由受控排版补入。透明背景须检查实际alpha；不要因提示词写了“透明”就勾选通过。

## C. 局部修改：仅用于允许重绘的概念插画区域

```text
任务是编辑现有图片，不是重新设计整张图。
图1是编辑目标；{{图2等的角色，无则删除}}。
唯一允许修改的区域：{{准确位置、范围与对象；必要时使用已提供的受控蒙版}}。
将该区域的{{原内容}}改为{{目标内容}}。
新文字仅为：“{{准确文字；不改字则删除}}”。
保持不变：{{逐项列出其余文字、图形、颜色、箭头、位置、比例、背景及画布边界}}。
风格继承：新内容匹配原图的{{笔触/光照/配色/线宽等实际特征}}，不要顺便重绘其他区域。
输出与原图同尺寸、同方向，保留{{透明/原背景}}；只实施本次局部变更，不添加新对象或解释文字。
```

真实曲线、坐标、软件截图和精确图例修改使用原生对象编辑或确定性局部合成，不使用此生图模板。用户要求蒙版外像素不变时，即使概念插画也需要在生成后只合成授权区域，并检查保护区差异；单靠“保持不变”的提示词不能保证零差异。

## D. 成果整页：给排版/合成工具的任务模板

此块不发给生图模型。保留实际证据文件，用确定性工具排版文字和数据；若需要背景插画，只把概念部分单独按A或B处理。

```text
交付：{{完整页面图片及指定格式/用户明确选择后的可编辑演示文件}}；页面尺寸与参考：{{实际比例、版心及风格参考}}。
标题：“{{准确标题}}”；本页研究问题：{{问题}}。
素材清单：
- {{素材文件/已绑定资产标识}}：{{本次证据类型}}；来源{{位置}}；影响解释的时间、版本或条件{{已核实信息；未核实处说明}}。
- {{其他素材；没有则删除}}。
保留范围：{{本次证据的原图内容、摘录文字、数据或图形关系}}，不得由生成模型描摹、补画或改写。
布局：{{各素材的占位与比例、必要注释及对应关系}}；证据图优先保留可读面积。
受控文字层：{{本次需要的标题、注释、摘录或结论的准确文本，以及各自位置}}；对应来源{{本次采用格式的可追溯出处}}。
定量展示时的口径：{{实际涉及的变量、单位、尺度或基准；非定量任务删除此行}}。
统计分析时的定义：{{实际涉及的样本、观察范围与不确定性定义；非统计任务删除此行}}。
比较或解释边界：{{哪些证据能够比较、哪些条件不同；结论支持范围与不确定性}}。
允许操作：{{等比例缩放、经确认的裁切、图外标注；由真实数据重绘时写明数据与变换}}。
验收：来源与影响解释的条件准确；材料与说明对应；证据与原件一致；结论不超出证据范围；最终文件已打开逐字与视觉核查。
```

缺少关键口径时先完成可做的版式和来源整理，保留待核实状态，不编造改善百分比或伪造完整条件。

## E. 可编辑复刻：给演示文稿工具的任务模板

执行者尚未明确时按主文件询问；已明确交给agent时直接填充并执行。用户自己复刻时，只准备其需要的素材与说明，不用此任务书启动演示文件制作。

```text
执行者：用户已明确选择agent复刻。
输入：{{参考图/原PPT与目标页段}}；交付：可编辑PPTX与所需预览。
本次范围：{{页段和允许改变的内容}}；保护：{{其余页面与对象}}。
原生对象清单：{{文字、形状、连接线、表格、公式与有源数据的图表}}。
证据图片清单：{{须原样保留的照片、论文图与截图}}；不能全部原生编辑的局部项：{{如有则逐项说明}}。
重建要求：{{画布、版心、坐标、字体、颜色、层次、线型、上下标和连接方向}}。
禁止以整页底图、单个SVG或图片拼图冒充对象可编辑；不描摹伪造研究证据。
验收依据：{{参考图与对象清单}}；检查包结构、真实对象类型、同尺寸渲染差异；有编辑器时检查代表对象修改并保存后的结果，没有时说明实际检查边界。
```

## F. 完整填写示例：抽象流程配图

本例只演示如何填模板。假设用户已明确：独立透明PNG，横向三步流程，只用深灰图形，不放文字，步骤只表示顺序。该画幅、颜色和步骤数仅适用于这个示例请求，其他任务从自身材料重新填写。

```text
请生成一张用于学术汇报的独立流程配图，不是整页演示页面。
没有输入图片。采用横向构图，真实透明背景，三个简洁节点从左到右依次排列，节点之间用同向箭头连接。箭头只表示步骤顺序，不表示因果、数值大小或效果优劣。三个节点同等大小与视觉权重，排列间距一致，边缘留有空隙，主体完整。
全部图形采用深灰色，线条清楚、克制，适合放在浅色页面。节点与箭头表达结构即可，不加入特定学科的对象、仪器、数据曲线或装饰图标。
图内不放文字、字母、数字或符号标签，不添加标题、正文、页脚、水印、相框或屏幕外壳。本次只交无字配图，不由agent补字。
背景为真实透明，不画白色矩形或棋盘格图案；主体不能被误抠除。只输出这一张独立PNG，不拼成整页。
```

按 [checklist](checklist.md) 的共用、独立素材和透明项验收；有因果或科学含义的图形仍须回到本次材料核对，不把本例的三步顺序迁移过去。尚未生成文件时，alpha和最终视觉项记“未检查”。
