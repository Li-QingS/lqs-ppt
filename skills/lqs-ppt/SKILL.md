# LQS 科研 PPT 制作

这是一套源于 LQS 科研汇报习惯的默认规范，当前调用者的要求和参考模板优先。以用户认可的叙事和现有学术风格为基础，让图形准确解释研究问题、方法与结果。适用于论文展示、科研平台汇报及相关配图；不把科研展示写成教材、产品广告或软件仪表盘。

## 规则优先级

当前请求中的明确要求 > 本次任务中最新确认的方案与参考页 > 本 skill 的历史偏好 > 外部技能的默认建议。历史要求只在其适用范围内生效。科研事实、公式和数值须核对原论文或原始实验材料；发现矛盾时说明冲突，不能为了符合说法而改造证据。

已有信息足够时直接完成授权工作。用户说“先讨论”“不生图”“不要操作 PPT”时，以该阶段为边界；后续明确要求生成或编辑后，按新授权继续，不重复询问已确定事项。可编辑复刻的执行者按下文单独选择。

## 先确定交付类型

| 用户要求 | 应交付 | 执行边界 |
|---|---|---|
| 讨论框架、给修改建议、写一句话 | 文本方案或文案 | 不生图，不修改演示文件 |
| 生成这一页、整页画面 | 包含标题、图文、标注的完整页面图 | 不只交插图，不自动操作原 PPT |
| 单独生成某张配图 | 指定配图文件 | 不擅自生成整页；透明背景按需保留 alpha 通道 |
| 可编辑 PPT、按参考图复刻 | 先询问由谁复刻，再按选择交付 | 用户自己复刻时给参考图与必要素材；交给 agent 时制作可编辑 PPTX |
| 修改已有 PPT 的指定范围 | 该范围内的实际文件修改 | 保护未授权区域及原件，输出可审阅版本 |

没有另行说明时，延续当前任务最近确认的交付类型；新任务只说“生成 PPT”且上下文无法判定时，采用用户常用的整页图片方案并简短说明。要求制作可编辑文件或按参考图复刻时，先完成下面的执行者选择；已有演示稿的局部修改进入对应编辑分支。

### 可编辑复刻前先选择执行者

需要制作可编辑 PPT 或按参考图复刻时，先问用户：**“这一步你想自己在 PPT 中复刻，还是交给 agent 复刻？”** 提供两个选项：

1. **我自己复刻**：交付本次需要的整页参考图、必要配图或简短复刻说明，由用户在 PPT 中完成；agent 不创建或修改可编辑 PPTX。
2. **交给 agent 复刻**：确认后由 agent 重建可编辑文字、图形、连接线等对象，并按可编辑文件流程验收；不能把整页图片装进 PPTX 冒充复刻。

用户未回答时等待选择，不用默认选项、等待时长或“需要可编辑 PPT”这句话代替回答；期间可以只读核对参考材料。当前任务中用户已明确选择“我自己复刻”或“交给你/agent 复刻”时，沿用该选择，不重复提问。只要求可编辑或复刻效果，不等于已经选择执行者。

整页 PNG、独立配图、框架讨论及已有 PPT 的局部修改不额外触发此问题，除非本次要求实际涉及可编辑重建。这个选择只决定由谁完成复刻，不增加其他制作阶段的审批。

制作整页图片、配图或可编辑文件前，读取 [制作与验收](references/production-and-qa.md)。处理 GMI、有限配置库或波形平台时，再读取 [项目专用约束](references/project-context.md)。仅核查历史规则来源时读取 [来源索引](references/source-ledger.md)；使用录音意见、写研究现状或设计引用时读取 [文案与引用](references/writing-and-citations.md)。

## 制作流程

### 1. 核对材料和有效范围

先读用户指定论文、现有 PPT/PDF、参考页及修改意见。识别哪些页面已经认可、哪些是中间稿、哪些仅供提取内容。论文作为内容来源时，不自动沿用其排版；PPT 作为风格参考时，提取真实模板参数。

整理本次必需的信息：听众、展示目的、当前阶段、页数或页段、交付类型、参考样式、内容依据、需要保护的区域。可从材料推断的事项自行核实；只有影响结论或交付且无法核实的信息才向用户澄清。

录音任务先保留原始转写，再单独提炼修改清单。逐字稿不混入润色、总结或推测；听不清的词明确标记。把每条意见对应到具体页面和验收点，不能用概括性的“已优化”代替逐项核对。

### 2. 梳理整段叙事

论文展示通常依次交代：背景与价值、研究问题及挑战、相关研究、问题建模与解决思路、创新、结果验证、局限与展望。按当前篇幅合并或拆页，不固定总页数。

研究动机说明“为什么值得研究”；问题建模把实际需求转成明确研究对象；本文思路说明“怎样解决”；创新说明相对已有工作的新增认识；结果回答“有什么证据”。相邻页承担不同职责，不能只换标题重复同一组功能或目标。

宏观问题先于具体波形、参数或算法案例。案例用于解释问题，不能让观众误以为研究只适用于该案例。给出方法之前，补足听众理解它所需的概念与约束；不在背景页突然出现未经解释的符号或覆盖几何。

### 3. 确定逐页内容

生成前，为每页明确五项：**标题、唯一主旨、解释该主旨的图、必要文字、证据及结论边界**。讨论阶段可用表格交给用户；已有确认框架且已要求制作时，不新增审批步骤。涉及可编辑复刻时，执行者选择仍须先完成。

标题直接说明主题，优先简短中文或清晰陈述，不强制每页写成结论句或问句。页底需要总结时，用一句凝练、有实际信息的结论收束；必要时使用“因此”“但”等关系词，不写口号或空泛价值判断。

图文必须能相互解释：遮住文字，图仍能说明关键关系；遮住图，文字能让人知道该画什么。场景、因果、约束、对比、选择与结果要在图中具体可见。单一图标不能代替一句研究判断。

### 4. 延续样式并安排版式

从有效参考页提取画布比例、版心、标题位置、字体、主辅色、强调色及图形语言。维持整套学术风格；局部替换不能带来整页风格漂移。没有可用模板时，可采用简洁红蓝学术风格；不虚构用户已经确认的具体色值。

配图中文优先微软雅黑，字母与数字优先 Times New Roman；关键标签和图例清楚、必要时加粗。历史中反复指定的 32 pt 及以上可作为独立配图关键文字的等效字号起点；参考页或当前要求优先。此偏好不等于正文、脚注和文献全部至少 32 pt。位图字号按最终插入尺寸检查，不能只相信提示词中的字号。

内容丰富依靠有解释力的图、比较和必要条件，不依靠堆字。让主要图形获得足够面积，并使区域边界、对齐和阅读顺序清楚。避免大块无用途空白、挤在一起的小模块、无含义图标、卡片墙和抢眼装饰。不要为填空白重复同一设备或同一现象，也不要把可视化简单替换成整块文字。

局部修改先锁定文字、图形、曲线和布局中的保留项。能通过精确编辑完成时，不重新生成未授权区域。

### 5. 按图的性质制作

**概念示意图**允许使用图像生成模型增强直观性；**科学证据图**必须保留原图，或由真实数据可追溯地重绘。不能让生图模型重新解释真实曲线、实验数值、截图或精确公式。整页图片同样遵守这条边界：可把原始证据与核对过的文字确定性合成到最终页面。

按 [制作与验收](references/production-and-qa.md) 执行所选输出分支。当前环境有相应技能时，图像生成读取 `imagegen`，PPTX 文件制作读取 `presentations:Presentations`；本 skill 不规定旧模型名称、API key 或固定软件库。环境未提供同名技能时，使用可用的图像生成或演示文稿工具执行同等流程；工具缺失不能降低证据保真与可编辑性要求。用户指定工具时先核实可用性，不能声称使用了实际未调用的工具。

### 6. 验收后交付

独立检查内容与视觉。内容检查覆盖术语、公式、曲线图例、数字、单位、引用、结论适用条件和页面分工；视觉检查打开实际最终图片或渲染文件，检查版心、字体、疏密、边界、遮挡和图文对应。修复后重新检查受影响页面。

可编辑文件额外检查包结构、对象编辑能力及重新保存后的渲染。局部编辑核对保护区域；真实截图标注核对原图和未标注区域。文件可打开或自动检查通过，不代表科学内容或视觉已合格。

交付用户要求的最终文件。批量任务核对文件数与页序；只承诺实际检查过的范围。图像生成提示词按相应技能要求保存；不把试错记录、中间版本或内部检查过程放进页面。存在影响使用的缺项、近似或无法验证之处时简短说明。
