# 学术科研 PPT 制作

根据本次研究材料、听众与展示目的，组织学术叙事、设计页面和配图，并核查最终交付。适用于不同学科、语言和研究方法；内容、符号、样式及输出形式从当前任务取得。

## 输入与边界

当前请求和本次已确认方案优先于通用建议。只从当前材料判断学科、研究对象、术语、方法、数据、听众、语言与模板；其他任务的内容和示例不能作为本次事实或默认设定。

先识别交付类型：

| 本次要求 | 对应交付 | 边界 |
|---|---|---|
| 讨论框架、给建议或写文案 | 文本方案 | 不自动生图或修改文件 |
| 整页图片 | 完整页面图 | 含本次要求的页面元素，不只交配图 |
| 独立配图 | 指定素材 | 不擅加整页标题、正文和页脚 |
| 可编辑演示稿或参考页复刻 | 按执行者选择处理 | 先确定由用户还是 agent 完成 |
| 已有演示稿的局部修改 | 授权范围内的新版本 | 保留未授权页面与对象 |

延续本次任务已明确的交付形式。上下文不能判断要演示文件、整页图片还是独立素材时，简短确认，不根据历史习惯默认某一种。若回答已同时明确执行者，不再追加同一问题。

用户要求“先讨论”“不生图”或“不修改原文件”时遵守该阶段；获得后续明确指令后继续相应工作，不重复询问已有答案。只澄清影响内容或交付且无法从材料取得的信息。

### 可编辑制作与复刻的执行者

需要可编辑演示稿或按参考页复刻时，先问：**“这一步你想自己在 PPT 中制作/复刻，还是交给 agent 完成？”**

- **用户自己完成**：提供本次需要的参考图、素材或简短说明，不创建或修改可编辑演示稿。
- **交给 agent**：制作所需可编辑对象并验证，不能把整页图片装进演示文件冒充原生可编辑。

用户未回答时等待，可先只读核对材料；默认选项和等待时长不代替选择。当前任务已明确交给谁时沿用，不重复提问。整页图片、独立素材、框架讨论及普通局部修改不触发此问题，除非实际涉及可编辑重建。

## 按任务读取资源

- 进入实际图片或演示文件制作时，读 [制作与验收](references/production-and-qa.md)。
- 准备生图、排版或复刻任务时，按 [提示词模板](references/prompt-templates.md) 选择对应模板并填入当前任务信息。
- 制作前和交付前，执行 [checklist](references/checklist.md) 的共用与适用分支；只有实际验证通过才能勾选。
- 处理叙事、术语、修改意见或引用时，读 [文案与引用](references/writing-and-citations.md)。

只加载当前需要的资源，不要求为简单讨论读取所有制作细节。

## 工作流程

### 1. 理解材料

读取用户指定的论文、数据、现有演示稿、参考页和修改意见。区分内容来源、样式参考、编辑目标与必须保留的证据；示例中的旧内容不能自动带入新页。记录受保护内容及尚未核实的信息。

从当前上下文确定听众、展示目的、语言、时长或篇幅、交付形式、模板与证据范围。没有提供的技术条件、数据、方法、结论和引文不自行补造。

### 2. 组织叙事

按研究问题和材料选择叙事结构。背景、问题、方法或论证、证据与发现、讨论或局限等是可选组成，不是所有学科都必须依次使用的固定目录。报告类型、页数与篇幅服从本次任务。

先建立听众理解所需的概念，再介绍专门术语、方法和结论。分别说明研究动机、实际工作与得到的证据，避免相邻页重复同一信息。纯综述、理论分析、实证研究与研究计划使用各自适合的论证方式。

### 3. 设计页面与图文

每页明确标题、核心信息、支持它的图或材料、必要文字及结论边界。标题使用当前汇报语言，直接说明主题；是否采用结论句、设置总结条或分栏，由页面功能决定。

图形表达真实的对象和关系，箭头的先后、因果、关联、调用或数据传递含义清楚。装饰图标不能替代论证；不能把流程顺序误画成因果。图文应能相互解释，信息不依赖未定义符号。

从当前模板提取画布、版心、字体、颜色、标题位置与图形语言。没有模板时，根据听众、显示条件与内容选择清晰一致的样式，并说明必要假设；不固定主题配色、字体、字号、布局比例或页数。混合文字、数学符号和不同书写系统时检查字形覆盖及排版一致性。

按最终显示尺寸检查文字和线条，不只依赖像素数或提示词中的字号。先减少重复内容、调整图文结构，再考虑压缩文字。已有确认方案且已要求制作时直接执行，不增加逐页审批。

### 4. 制作并保护证据

区分概念示意与作为研究证据的原图、观察记录、数据图和精确文本。概念视觉可以生图；原始证据保留原件，或根据可追溯数据确定性重绘。精确公式、引用和密集正文采用受控排版。最终交图片也不能让生成模型重画证据或改写数值。

填写 [模板A–E](references/prompt-templates.md) 的相应分支，写清当前素材角色、主旨、关系、准确文字、版式、保留项和输出意图；发送给工具前替换字段并删除不适用行。模板和示例只提供结构，不能成为新任务的内容来源。

使用当前环境可用且适合任务的图像、排版或演示文稿工具，遵循其实际说明。若有相关工具技能，按需读取；不依赖固定工具名、旧模型或本机路径。缺少所需能力时完成可做部分并说明缺项，不伪称生成或验收。

### 5. 核查与交付

按 [checklist](references/checklist.md) 逐页或逐素材记录状态。核查科学内容、来源、关系、准确文字及实际最终文件的视觉；涉及定量图或比较时核查变量、单位与基准，涉及统计结论时再核查样本及不确定性。局部编辑验证保护区，可编辑文件验证真实对象与渲染。

把通过、失败、未检查和不适用分开记录；提示词承诺、文件可打开和自动检查通过都不能单独证明完整合格。修复后检查新版本。

交付本次要求的最终文件及必要说明，核对范围、数量、顺序与链接。按任务及实际工具要求保存最终提示词或制作任务书；检查记录与工作过程不嵌入演示页面。明确影响使用的缺项和验证范围。
